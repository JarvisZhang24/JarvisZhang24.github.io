写给自己的备忘，让下一篇文章的准备工作只需要两分钟。

## 文章位置

```
src/content/blog/en/<slug>.md    → /blog/<slug>/
src/content/blog/zh/<slug>.md    → /zh/blog/<slug>/
```

目录名就是语言标识。**两个目录下使用相同的 slug**，页首的语言切换就会在两篇译文之间跳转；
如果某一侧没有对应文章，则回落到该语言的文章列表页，不会出现死链。

## Frontmatter 字段

| 字段          | 必填 | 用途                                 |
| ------------- | ---- | ------------------------------------ |
| `title`       | 是   | 文章标题、浏览器标签页与列表标题     |
| `description` | 是   | 显示在标题下方，同时用于社交预览     |
| `date`        | 是   | 排序依据与显示日期                   |
| `updated`     | 否   | 在文章头部增加一行「更新于」         |
| `tags`        | 否   | 渲染为等宽字体标签                   |
| `draft`       | 否   | 设为 `true` 时不会进入生产构建       |

## 草稿

标记了 `draft: true` 的文章在 `bun run dev` 下可见，`bun run build` 时会被剔除。
因此可以放心地把没写完的稿子留在仓库里，只要不去掉这个标记，就不会出现在线上。

## 阅读时长

根据正文估算，中日韩字符与以空格分词的单词分别计数，
这样中文文章不会被算出一个明显偏短的时长。
